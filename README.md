# Graph Theory (2301CS595) - Practical Codes

This repository contains all the practical C programs for the **Graph Theory (2301CS595)** course (B. Tech Semester-5). 

All the code is properly formatted, commented, and organized problem-wise according to the official lab manual.

## 📂 Repository Structure

All practicals are located inside the `All_Labs/` directory.

| Lab | Problem | File Name | Description |
| :---: | :---: | :--- | :--- |
| **1** | 1 | `Lab01_Adjacency_List.c` | Represent the adjacency list of a directed graph. |
| **1** | 2 | `Lab01_Basic_Graph_Operations.c` | Basic graph operations (Adjacency Matrix, Degree, Properties). |
| **2** | 1 | `Lab02_Breadth_First_Search.c` | Breadth First Search (BFS) traversal. |
| **3** | 1 | `Lab03_Depth_First_Search.c` | Depth First Search (DFS) traversal. |
| **4** | 1 | `Lab04_Tree_Operations.c` | Tree operations (Pendent vertices, Degree, Distance Matrix, Eccentricity, Center). |
| **5** | 1 | `Lab05_Friend_Circles.c` | Find total number of connected components (Friend Circles). |
| **5** | 2 | `Lab05_Spanning_Tree_Properties.c` | Spanning trees, branches, chords, fundamental circuits, rank, and nullity. |
| **6** | 1 | `Lab06_Articulation_Points.c` | Identify articulation points (cut-vertices) in a graph. |
| **7** | 1 | `Lab07_Connectivity_Separability.c` | Determine vertex/edge connectivity and separability of a graph. |
| **8** | 1 | `Lab08_Dominating_Set.c` | Find dominating sets and domination number. |
| **9** | 1 | `Lab09_Total_Dominating_Set.c` | Find total dominating sets and total domination number. |
| **10** | 1 | `Lab10_Graph_Matching.c` | Maximal matching, Maximum matching, and Perfect matching. |
| **11** | 1 | `Lab11_Halls_Condition.c` | Verify Hall's condition for a given bipartite graph. |
| **12** | 1 | `Lab12_Graph_Matrices.c` | Construct Adjacency, Degree, and Laplacian Matrix. |

| **14** | 1 | `Lab14_Spectral_Clustering.c` | Perform spectral clustering on a graph. |

## 🚀 How to Run

1. Make sure you have a C compiler installed (e.g., `gcc`).
2. Open your terminal or command prompt.
3. Compile the desired program:
   ```bash
   gcc All_Labs/Lab01_Adjacency_List.c -o output
   ```
4. Run the executable:
   ```bash
   ./output
   ```
